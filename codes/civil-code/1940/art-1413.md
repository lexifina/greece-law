# Άρθρον 1413

᾿Εὰν εἰς τὸν ἄνδρα μετεβιβάσθη ἢ χυριότης τῶν εἰς προῖκα ἐπιδοθέντων, ἀντικείμενον τῆς προικὸς εἶναι ἡ ἐν τῷ προικοσυμφώνῳ συμφωνηθεῖσα. χρηματικὴ ἀξία αὐτῶν. ᾿Εὰν ἡ ἀξία δὲν προόσδιωρίσθη, ἢ προσδιωρίσθη ἀνακαιβῶς, λαμβάνεται ἡ κατὰ τὸν χρόνοῦ τοῦ προικοσυµφώνου ἀληθὴς ἀξία,
