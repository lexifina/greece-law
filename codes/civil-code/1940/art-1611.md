# Άρθρον 1611

Αἱ διατάξεις τῶν ἄρθρων 1622 ἕως 1627 ἐφαρμόζονται καὶ εἰς τοὺς παρεπιτρόπους. ᾿Αλλ᾽ ὁ ἐπίτροπος δὲν δύναται νὰ προκαλέσγ τὴν παῦσιν τοῦ παρεπιτρόπου, οὔτε δύναται νὰ εἶναι μέλος τοῦ πρὸς τοῦτο συγκαλουμένου συγγενικοῦ συμβουλίου. |
