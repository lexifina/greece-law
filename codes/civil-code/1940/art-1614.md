# Άρθρον 1614

Ἔὰν ὁ ἐπίτροπος ἔχῃ κατοικίαν διάφορον τῆς τοῦ πατρὸς τοῦ ἀνγλίκου, ἢ ἄν μεταθέσῃ ἀλλαχοῦ τὴν κατοικίαν του, τὸ μέχρι. τοῦδε ἁρμόδιον δικαστήριον, αἰτήσει τοῦ ἐπιτρόπου, δύναται νὰ ὁρίσῃ ὡς τόπον καταρτίσεως τοῦ συγγενικοῦ συμβουλίου τὴν κατοικίαν τοῦ ἐπιτρόπου. ᾿
