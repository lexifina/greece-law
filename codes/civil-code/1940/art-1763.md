# Άρθρον 1763

_Πλαγιότιτλος (margin title, OCR): νάμλη_

Πᾶσα διαθήκη δύναται νὰ. ἀναθῇ - 1. διὰ τῆς περὶ τούτου δηλώσεως ἐν μεταγενεστέρᾳ διαθήκῃ, ἐὰν ἡ μεταγενεστέρα αὕτη ἀνακληθῇ, ἡ διαθήκη ἐνεργεῖ ὡσεὶ μὴ εἶχε καταργηθῆ; 2. διὰ δηλώσεως γινομένης ἐνώπιον συμβολαιογράφου ἐπὶ παρουσίᾳ τριῶν μαρτύρων χαὶ κατὰ τὰς λοιπὰς διατυπώσεις τῶν συμβολαιογραφικῶν ἐγγράφων. ᾿Εὰν ἡ δήλωσις αὕτη ἀνακληθῇ καθ᾽ ὅμοιον τρόπον, ἡ διαθήκη ἐνεργεῖ ὡσεὶ μὴ εἶχεν ἀναχληθῇ.
