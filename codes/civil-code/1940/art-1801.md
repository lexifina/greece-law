# Άρθρον 1801

<!-- text: OCR of official scan -->

_Πλαγιότιτλος (margin title, OCR): "Ἐγμαπάστασις ὅτι “μέρους τῆς κλη-_

'- "Εὰν- ἐγκατεστάθη εἷς μόνος κληρονόμος περιορισθεὶς εἰς ποσοστὸν τῆς Ἀληῤονομίας, ὡς πρὸς τὸ ὑπόλουπον βέρος χωρεῖ ἡ ἐξ ἀδιαθέτου διαδοχή. Τὸ αὐτὸ ἰσχύει καὶ” ὅταν ἐγκατεστάθησαν πλείονες κληρονόμοι, ἔκαστος δὲ τούτων περιωρίσθη εἰς ποσοστὸν καὶ τὰ ποσοστὰ δὲν ἐξαντλῶσι τὸν κλῆρον.
