# Άρθρον 1826

_Πλαγιότιτλος (margin title, OCR): Διαδοχὴ ἢ προσα Έπσις ἔν τῇ ν μίμῳ μοίρᾳ_

- ὰν καθόλου ἢ ἐν μέρει μεριδοῦχός τις ἀπεκληρώθη νομίμως, ἢ. παρῃτήθη ἐξέπεσε τούτου λόνῳ ἀναξιότητος, τὸ ὃ εκαίωμααι τῆς νομίμου μοίρας ἆσ κοῦσιν οἱ κατὰ τὴν σειρὰν τῆς ἐξ ἀδιαθέτου διαδοχῆς ἐρχόμενοι μεριδοῦχοι,. 5
