# Άρθρον 1884

<!-- text: OCR of official scan -->

_Πλαγιότιτλος (margin title, OCR): Κουνωνία_

᾿Εὰν οἱ κληρονόμοι εἶναι πλείονες, ἡ χληρονομία καθίσταται κοινὴ κατὰ λόγον τῆς μερίδος ἑκάστου. ᾿Επὶ τῆς. μεταξὺ τῶν συγκληρονόµων κοινωνίας, ἐφ᾽ ὅσον ἐν τῷ νόμῳ δὲν ὁρίζεται ἄλλως, ἐφαρμόζονται αἱ γενικαὶ περὶ κοινωνίας διατάξεις.
