# Άρθρον 238

_Πλαγιότιτλος (margin title, OCR): Ἔγκοισ -ᾱ-_

Ἢ μετὰ τὴν ἐπιχείρησιν τῆς δικαιοπραξίας παρεχομένη συγκατάθεδις (ἔγκρισις), ἐφ᾽ ὅσον δὲν ὁρίζεται τὸ ἐναντίαν, ἀνατρέχει. εἰς τὸν χρόνον τῆς δικαιοπραξίας.' Εκ τῆς ἀναδρομιικῆς ἐνερ-- γείας δὲν ἐπηρεάζονται τὰ πρὸ τῆς ἐγκρίσεώς ἀποκτηθέντα δικαιώματα τρίτων. -
