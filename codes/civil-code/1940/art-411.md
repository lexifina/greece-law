# Άρθρον 411

_Πλαγιότιτλος (margin title, OCR): Δυμαίωμᾳ τοῦ τρίτου ._

Ὃ τρίτος δικαιοῦται νὰ ἀπαϊτήσῃ τὴν παροχὴν ἀπὸ τὸν ὑποσχεθέντα ἀπ᾿ εὐθείας, ἐὰν προκύπτῃ τοιαύτη θέλησις: τῶν συμβληθέντων μερῶν ἣ συνάγεται τοῦτο ἐκ τῆς φύσεως καὶ τοῦ σκοποῦ τῆς συμβάσεως. ᾿
