# Άρθρον 838

<!-- text: OCR of official scan -->

_Πλαγιότιτλος (margin title, OCR): μυσθέντων_

- 0 ξενοδόχος ἔχει νόμιμον ἐνέχυρον ἐπὶ τῶν εἰσκομισθέντων ὑπὸ τοῦ πελάπου πραγμάτων διὸ τὰς ἀπαιτήσεις αὐτοῦ ἐκ τῆς διαμονῆς τοῦ πελάτου ἐν τῷ ξενοδοχείῳ καὶ ἐκ τῶν συναφῶν παροχῶν. Αἱ περὶ τοῦ νομίμου ἐνεγύρου τοῦ ἐκμισθωτοῦ ἀκινήτου διατό- - μὲ ᾿ ἕξεις ἐφαρμόζονται ἀναλόγως.
