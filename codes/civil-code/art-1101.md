# Άρθρο 1101

<!-- text: OCR of official scan -->

Αξίωση αναγκαίων δαπανών. Ο καλόπιστος νομέας έχει δυκχίωμχ να απαιτήσει από τον κύριο αποζημίωση για δαπάνες που έγιναν στο πράγμα, προκειμένου να διατηρηθεί κατάλληλο για τακτική εχμετάλλευση (αναγκαίες δαπάνες), καθώς και για την πληρωμή βαρών του πράγματος. Για συνηθισμένες όμως δαπάνες συντήρησης του πράγματος δεν έχει δικαίωμα αποζημίωσης, εφόσον του έμειναν τα ωφελήματα του πράγματος.
