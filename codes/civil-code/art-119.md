# Άρθρο 119

<!-- text: OCR of official scan -->

Μεταβολή του οργανισμού. 0 οργανισμός του ιδρύματος μπορεί να μεταβληθεί, ακόμη αι αντίθετα προς τη θέληση του ιδρυτή, αν το ζητήσει η διοίκηση του ιδρύματος και αν ή μεταβολή επιβάλλεται για να συντηρηθεί ή περιουσία του ή για να εκπληρωθεί ο σκοπός του.
