# Άρθρο 1247

<!-- text: OCR of official scan -->

Ενέχυρο σε δικαίωμα. Ενέχυρο μπορεί να συσταθεί και σε δικαίωμα, εφόσον αυτό είναι μεταβιβάσιμο. Η σύσταση γίνεται κατά τον τρόπο που γίνεται και ή μεταβίβαση του δικαιώματος. Η σύμβαση για τη σύσταση του ενεχύρου απαιτείται να γίνει με έγγραφο συμβολαιογραφικό ή ιδιωτικό με βέβαιη χρονολογία.
