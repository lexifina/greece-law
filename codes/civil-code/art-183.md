# Άρθρο 183

<!-- text: OCR of official scan -->

Επικύρωση. Επικύρωση άκυρης δικαιοπραξίας ισχύει σαν νέα κατάρτιση της. ᾽ Αν οί συμβαλλόμενοι επικυρώσουν άκυρη σύμβαση, σε περίπτωση αμφιβολίας δημιουργείται αμοιβαία μεταξύ τους υποχρέωση για κάθε παροχή που θα όφειλαν, αν ή σύμβαση ήταν έγκυρη από την αρχή.
