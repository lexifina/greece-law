# Άρθρο 189

<!-- text: OCR of official scan -->

Αποδοχή της πρότασης. Ή αποδοχή της πρότασης για τη σύναψη σύμβασης απαιτείται να περιέλθει σ᾽ αυτόν που πρότεινε μέσα στην προθεσμία που είχε τάξει. Αν δεν είχε τάξει προθεσμία, η αποδοχή πρέπει να περιέλθει σ᾿ αυτόν έως τη στιγμή που κατά τις περιστάσεις ήταν υποχρεωμένος να την περιμένει.
