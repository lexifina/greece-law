# Άρθρο 335

Αδυναμία για εκπλήρωση. Αν κατά την εκπλήρωσή της ή παροχή είναι ολικά ή μερικά αδύνατη για λόγους που είτε είναι γενικοί είτε αφορούν τον οφειλέτη, αυτός έχει υποχρέωση να ανορθώσει τη ζημία του δανειστή που επέρχεται από την αδυναμία.
