# Άρθρο 616

<!-- text: OCR of official scan -->

Οι προκα-αβολές ᾿μισθωμάτων, που έγιναν στον έαρι σθωτή που εκποίησε ή οί εκχωρ σεις μισθωμάτων,που έγιναν απ΄ αυτόν, καθώς και οί κα’ ασχέσεις μισθωμάτων, που έγιναν από δανειστές του, είναι αυίσχυρες απέναντι στο νέο Χτ Ίτορα. για μισθώματα πέρα από τρεις μήνες, που αρχίζουν από τότε που αυτός γνωστυποίησε στο μισθωτή την εκποίηση.
