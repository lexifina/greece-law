# Άρθρο 622

<!-- text: OCR of official scan -->

Υποχρεώσεις του εκμισθωτή. Ό εκμισθωτήης οφείλει αποζημίωση για τις έκτακτες επισκευές, καθώς επίσης και για τις βελτιώσεις που έγιναν στο μίσθιο, εφόσον αύξησαν την παραγωγικότητά του. Ό μισθωτήης έχει δικαίωμα να αφαιρέσει το κατασκεύασμα που πρόσθεσε στο μίσθιο.
