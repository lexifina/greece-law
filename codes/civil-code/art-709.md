# Άρθρο 709

<!-- text: OCR of official scan -->

“Έννοια. Εκείνος που δημόσια προκήρυξε αμοιβή για την εκτέλεση πράξης, ιδίως. για την επίτευξη αποτελέσματος, οφείλ-» την αμοιβή σ᾽ αυτόν που εκτέλεσε, και αν ακόμη αυτός ενέργησε άσχετα με την προχκ ήρυξη. Προκήρυξη επάλθου που πρόκειται να απονεμηεί ύστερα από διχγωνισμό, είναι ισχυρή μόνο αν περιέχει προθεσμέχ για τη διεξαγωγή του διαγωνισμού.
