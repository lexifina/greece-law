# Άρθρο 823

Υποχρεώσεις του θεματοφύλσκα. Ο θεματοφύλακας οφείλει να καταβάλει την επιμέλεια , που καταβάλει στις δικές του υποθέσεις, ᾽Αν όμως οφείλεται αμοιβή για τη φύλαξη, ευθύνεται για κάθε πταίσμα.
