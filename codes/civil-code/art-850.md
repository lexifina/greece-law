# Άρθρο 850

<!-- text: OCR of official scan -->

Εγγύηση για άχυρη οφειλή. Η εγγύηση προυποθέτει έγκυρη κύρια οφειλή. Είναι όμως ισχυρή Ή εγγύηση για οφειλή που συνομολογήθηκε από πρόσωπο ανίκανο ή περιορισμένα ικανό για δικαιοπραξία, αν ο εγγυητής εγγυήθηκε για το πρόσωπο αυτό γνωρίζοντας την ανικανότητά του.
