# Άρθρο 930

<!-- text: OCR of official scan -->

Ή αποζημίωση των δύο προηγούμενων άρθρων που αναφέρεται στο μέλλον κα-αβάλλε-αι σε χρηματικές δόσεις κα-ά μήνα. Ό-αν υπάρχει σπουδαίος λόγος, αποζημίωση μπορεί να επιδικαστεί σε κεφάλαιο εφάταξ. Ο οφειλέ-ης της αποζημίωσης μπορεί κατά τις περιστάσεις να υποχρεωθεί να παράσχει ασφάλεια. Ή αξίωση αποζημίωσης δεν αποκλείεται από το λόγο ότι κάποιος άλλος έχει την υποχρέωση να αποζημιώσει ή να διατρέφει αυτόν που αδικήθηκε.
