# Άρθρο 1032

<!-- text: OCR of official scan -->

1.0 διαχειριστής οφείλει να υποβάλλει κάθε έτος καθώς μοι ώταν περατωθεί η διαχείριση, έγγραφη λογοδοσία σε εκείνον υπέρ του οποίου έγινε και σε εκείνον ματά του οποίου εύχε στραφεί η εκτέλεση και στους δινειστές που αναγγέλθηκαν.

2. 0 διαχειριστής ευθύνεται, κατά τις διατάξεις του ουσιαστικού δικαίου, να αποζημιώσει εκείνον υπέρ του οποίου έγινε και εκείνον κατά του οποίου είχε σιραφεί η εκτέλεση και τους ξανειστές που αναγγέλθημαν.
