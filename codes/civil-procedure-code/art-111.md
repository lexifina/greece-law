# Άρθρο 111

<!-- text: OCR of official scan -->

Ί. Η διαδικασία στο οοιροατήριο στηρίζεται στην έγγραφη προδικασία.

2. Καμιά κύρια ή παρεμπίπτοιχχχ αίτηση για δικαστική προστασία δεν γπορεί να εισαχθεί στο δικαστήριο χωρίς να τηρηδεί προδικασία, εκτός αν ο νόμος ορίζει διαφορετικά. Η αίτηση που έχει έισαχϑει χωρίς προδικασία απορρίπτεται ώς απαράδεκτη και «αυτεπαγγέλτως.
