# Άρθρο 231

<!-- text: OCR of official scan -->

Στη διαδικασία ενώπιον του Ειρηνοδικείου η πρόσθετη παρέμβαση μπορεί να ασκηϑεί μαι προφορικά κατά τη δικάσιμο. Στην περύπτωση αυτή ό ειρηνοδίκης μπορεί να αναβάλε τη συζήτηση σε μεταγενέστερη δικάσιμο, που ορίζεται αμέσως αν κρίνει ότι αυτό είναι αναγμαί̈ο για την υπεράσπιση των διαδύκων
