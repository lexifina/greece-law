# Άρθρο 380

<!-- text: OCR of official scan -->

Οι πραγματογνώμονες μπορούν να λάβουν γνώση των στοιχείων της δικογραφίας που είναι, χρήσιμα για τη διεξαγωγή της πραγματογνωμοσύνης.

2. Το δωκαστήριο του άρθρου 379 ήο δικαστής. μπορούν να επιτρέψουν στους πραγμ τογνώμονες να ζητήσουν, πριν συντάξουν τη γνωμοδότησή τους, διευκρινίσεις από τους διαδίκους ή πληροφορίες από τρίτους ή να καταρτίοουν σχέδια ή ιχνογραφήματα, να πάρουν φωτογραφίες ή άλλες απεικονίσεις ή να κάνουν επιτόπια αραρμογή τίτλων ή τεχνικές ενέργειες ή να εξετάσουν έγγραφα ή βιβλία εμπόρων ή επαγγελματιών.
