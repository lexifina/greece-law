# Άρθρο 419

<!-- text: OCR of official scan -->

1. Η μη εμφάνιση κάποιου διαδίκου στη διμάσιμο που ορίστηκε για την εξέτασή του ή η αρνησή του να καταδέσει δεν. εμποδίζει να εξεταστεί άλλος διάδικος που εμρανίστημε.

2. Δεν επιτρέπεται να χρησιμοποιηθούν εξαναγκαστυμά μέτρα για να υποχρεωθεί [] διάδύος να προσέλθει και να.εξεταστεύ.
