# Άρθρο 666

<!-- text: OCR of official scan -->

1... Κατά τη διαδικασία. ενώπιον του μονομελούς πρωτοδικεύου εφαρμόζονται οί διατάξεις που ρυϑμίζουν τη διαδικασία ενώπιον των ειρηνοδικείων. ".

2. 0 ειρηνοδύκης, με αύτηση του εναγομένου, που υποβάλλεται κατά την πρώτη συζήτηση στο ακροατήριο έχει δικαίωμα να παραπέμψει την εκδύκαση της διαφοράς στο μονομελές πρωτοδικείο της περιφέρειας του, αν είναι εκκρεμής στο δικαστήριο αυτό αγωγή του εναγομένου κατά του ενάγωντος για απαύτηση από εκεύνες που αναφέρονται στο άρθρο 663 και αυτή επιδέχεται συμψιχρισμό με εκεύνη που παραπέμπεται.

3. Οι διατάξεις των άρθρων 466 έως 472 δεν εφαρμόζονται στις διαφορές που αναφέρονται στο άρθρο 663.
