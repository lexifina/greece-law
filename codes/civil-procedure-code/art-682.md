# Άρθρο 682

<!-- text: OCR of official scan -->

1. Κατά την ειδική διαδικασία των άρθρων 683 έως 703 τα δικαστήρια, σε επεύγουσες περιπτώσεις ή για να αποτραπεί επικέίμενος κίνδυνος, μπορούν να διατάζουν ασραλιστιμά μέτρα για την εξασράλιση ή διατήρηση ενός διμαιώματος ή τη ρύθμιση μιας κατάστασης και να τα μεταρρυϑμίζουν ή να τα αναμαλούν. Το διμαίωμα είναι δυνατό να εξαρτάται από αιρεσή ή ποοδεσμία. 2, Τα ασραλιστυιά μέτρα μπορούν να διαταχϑούν και κατά τη διάρμεια της δίκης που αφορά την κύρια υπόϑεση.
