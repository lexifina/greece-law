# Άρθρο 705

<!-- text: OCR of official scan -->

1. Αν διατάγϑηκαν ασραλιστιμά μέτρα για νανεξασραλιστεί χρηματική απαύτηση ή απαίτηση που μπορεί να μετατραπεί σε χρήματα, το δικαστήριο που τα διέταξε ή το δικαστήριο που δικάζει την κύρια υπόθεση έχει υποχρέωση, με αίτηση όποιου έχει έννομο συμφέρον, να αντικαταστήσει τα ασφαλιστικά μέτρα που είχαν διαταχθεί με εγγυοδοσία ύπερ εκείνου που τα ζήτησε. :

2. Αν διατάχθηκαν αυραλιστιμά μέτρα για να εξασφαλιστεί άλλο δικαίωμα, το δικαστήριο που. τα διέταξε ή το δικαστήριο που διμάζει την μύρια υπόθεση, έχει το διμαίωμα, με αίτηση όποιου έχει έννομο συμφέρον, μεταρρυθμίζοντας τη σχετική απόφαση, να διατάξει εγγυοδοσία υπέρ εκείνου που τα ζήτησε μόνο αν κατά τις περιστάσεις εξασραλίζετοι πλήρως το διμαίωμα.
