# Άρθρο 742

<!-- text: OCR of official scan -->

Οι ανήλικοι που έχουν συμπληρώσεν το δέκατο έκτο έτος της ηλικίας τους έχουν την υκανότητα να παρίστανται στο δικαστήριο για υποθέσεις που αφορούν την προσωπική τους κατάσταση και. να ασκούν κατά της απόρασης που εμδίδεται ένδικα μέσα και τριταναμοπή. Όταν παρίσταται ώ ανήλικος πρέπει να καλείται όποιος τον εμπροσωπεί νόμιμα.
