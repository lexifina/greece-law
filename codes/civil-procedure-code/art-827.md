# Άρθρο 827

<!-- text: OCR of official scan -->

1. 0 ειρηνοδίκης που διατάζει τη σφράγιση μπορεί να διατάξει κάθε πρόσρορο μέτρο για να επιτευχθεί η σφρράγιση. Ο ειρηνοδίκης μπορεί να διατάξει η αρράγιση να γίνει και κατά τη νύχτα.

2. Δεν μπορούν να σρραγιστούν τα υπνοδωμάτια που χρησιμοποιούνται από εκείνους που στεγάζονται στο διαμέρισμα όπου γίνεται η σφράγιση.

3. Αντυκμείμενα που είναι αναγκαία για να τα χρησιμοποιούν εκείνοι που στεγάζονται στο διαμέρισμα όπου γίνεται ή αρράγισ» δεν σρραγίζονται και παραδίδο- Ί νται σ᾽ αυτούς".

4. Αντιμείμενα των οποίων ή σρράγιση είναι αδύνατη ή επιζήμια λέν του είδους τους δεν σρραγίζονται και παραδίδονται για φύλαξη σε μεσεγγυσύχο που διορίζει εκείνος που ενεργεί τη σρράγιση. άν πρόκειται για αντικείμενα που μπορεί να υποστούν φϑορά)ο ειρηνοδίκης που διέταξε τη σρράγιση διατάζει την εκποιησή τους κατά τις διατάξεις για την αναγκαστική εμποίηση πραγμάτων τα οποία μπορούν να υποστούν φθορά.
