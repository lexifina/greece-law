# Άρθρο 829

<!-- text: OCR of official scan -->

1. 0 ειρηνοδίκης που διατάζει τη σρράγιση ορίζει μεσεγγυούχο των αντικειμένων που αρραγίζονται και ματά προτύμηση ορίζεται μεσεγγυούχος όποιος τα μοτέχει.

2. Τα κλειδιά των αντικειμένων που αρα γίζονται παραλαμβάνει όποιος ενεργεί τη σρράγιση και τα παραδίδει, με έγγραφη απόδειξη, στη γραμματεία του ειρηνοδικείου.

3. Όποιος ενεργεί τη σρράγιση οφείλει να ερευνήσει αν ως τη αρράγιση έχει αφαιρεθεί μάποιο αντικείμενο μαι να συγκεντρώνει κάθε σχετική πληροφορία.
