# Άρθρο 925

<!-- text: OCR of official scan -->

1. 0 καδολικός ή ειδικός διάδοχος του δικαιούχου δεν μπορεί να αρχίσει ή να συνεχίσει την αναγκαστική εκτέλεση πριν Αοινοποιηϑούν όδε εκείνον κατά του οποίου στρέφεται η εκτέλεση η έπιταγη μαι τα έγγραφα που τον νομιμοποιούν.

2. Όταν η αναγκαστική εκτέλεση που άρχισε πρόκειται να συνεχιστεί ᾿ κατά κληρονόμου ή κηδεμόνα σχολύΓσυστς κληρονομίας, απαιτείται να τους επιδοθεί προηγουμένως η επιταγή.
