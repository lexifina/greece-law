# Άρθρο 969

<!-- text: OCR of official scan -->

η. Ό πλειστηριασμός ολοκληρώνεται με την κατακύρωση. Όποιος υπερθεματίζει εσμεύεται ώσπου να γίνει καλύτερη προσφορά ή ώσπου να ματαιωθεί η αταχύρωση. ᾿ 2. Έως την καταπύρωση εκείνος κατά του οποίου στρέφεται η εμτέλεση έχει δικαίωμα να εξοφλήσει τα έξοδα και τις απαιτήσεις εκείνου που την επισπεύδει μαι των άλλων δανειστών που έχουν τίτλο εκτελεστό μαι αναγγέλδημαν, και να αναλάβει τα πράγματα που πλειστηριάζονται. Εκείνος κατά του οπούου έγινε η εκτέλεση έχει γος ί δικαίωμα να ενεχυριάζει τα πράγματα που πλειστηριάζονται για να βρει τα μέσα να Ι εξοφλήσει την απαίτηση και να πληρώσει τα έξοδα. -
