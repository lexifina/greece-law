# Άρθρο 262

Ως προς την ομοδικία, τη συνάφεια, την αντικειμενική σώρευση και τη συνεκδίκαση εφαρμόζονται αναλόγως οι αντίστοιχες διατάξεις των άρθρων 115 έεως και 125,

ΚΕΦΑΛΑΙΟ Ζ' ΔΙΚΟΛΟΓΙΚΗ ΙΚΑΝΟΤΗΤΑ ΤΩΝ ΔΙΑΔΙΚΩΝ άρθρο 263 Οι ξιάδικοι μπορούν να διενερνούν διαξικαστικές πρα-- έξις, και να παρίστανται κατά τη συζήτηση, χωρίς δικαστικοό πληρεξούσιο. ᾽
