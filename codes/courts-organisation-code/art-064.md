# Άρθρο 64

_ΚΕΦΑΛΑΙΟ ΣΤ’ · ΙΣΟΒΙΟΤΗΤΑ, ΑΡΧΑΙΟΤΗΤΑ, ΒΑΘΜΟΙ, · ΠΡΟΒΑΔΙΣΜΑ_

Ισοβιότητα δικαστικών λειτουργών Οι δικαστικοί λειτουργοί είναι ισόβιοι. Πριν από τον διορισμό τους ως τακτικών δικαστικών λειτουργών, διανύουν εκπαιδευτική και δοκιμαστική περίοδο με τις προϋποθέσεις και τους όρους που ορίζονται στις επόμενες διατάξεις.
