# Άρθρο 296. - Λόγοι

για την αντικατάσταση των περιοριστικών όρων με προσωρινή κράτηση. Οι περιοριστικοί όροι που επιβλήθηκαν στον κατηγορούμενο είναι δυνατό να αντικατασταθούν με προσωρινή κράτηση: α) αν, μολονότι προσκλήθηκε νόμιμα, δεν εμφανίζεται στον ανακριτή ή στο δικαστήριο για να δικαστεί, χωρίς να συντρέχουν εύλογα κωλύματα που να κάνουν αδύνατη την εμφάνισή του∙ β) αν έχει κάνει προπαρασκευαστικές πράξεις φυγής γ) αν παραβιάζει τους όρους που του επιβλήθηκαν ή δεν δηλώσει τη μεταβολή της κατοικίας του σύμφωνα με το επόμενο άρθρο.
