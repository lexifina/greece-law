# Άρθρο 26

Εγγυήσεις Για τη διασφάλιση της τελωνειακής οφειλής, οι τελωνειακές αρχές απαιτούν τη σύσταση εγγύησης από τον οφειλέτη ή από κάθε άλλο πρόσωπο που ενδέχεται να καταστεί οφειλέτης. Οι τελωνειακές αρχές δύνανται να επιτρέπουν τη σύσταση εγγύησης από τρίτο πρόσωπο, άλλο από εκείνο από το οποίο απαιτείται η εγγύηση σύμφωνα με το πρώτο εδάφιο.
