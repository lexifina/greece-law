# Άρθρο 77

Ειδικές περιπτώσεις επιστροφής του φόρου

1. Ο Ειδικός Φόρος Κατανάλωσης (Ε.Φ.Κ.) που έχει καταβληθεί για πετρελαιοειδή προϊόντα που έχουν μολυνθεί ή αναμειχθεί τυχαία και συνεπεία του γεγονότος αυτού κατέστησαν ακατάλληλα να χρησιμοποιηθούν για το σκοπό που προορίζονταν, επιστρέφεται ή συμψηφίζεται, εφόσον τα προϊόντα αυτά επανεισάγονται στη φορολογική αποθήκη για ανακύκλωση.

2. Οι όροι και οι διατυπώσεις εφαρμογής των διατάξεων της προηγούμενης παραγράφου καθορίζονται με απόφαση του Υπουργού Οικονομικών.
