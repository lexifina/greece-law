# Άρθρο 94

_ΤΜΗΜΑ Γ΄ · ΒΙΟΜΗΧΑΝΟΠΟΙΗΜΕΝΑ ΚΑΠΝΑ_

Είδη βιομηχανοποιημένων καπνών Βιομηχανοποιημένα καπνά, στα οποία επιβάλλεται Ειδικός Φόρος Κατανάλωσης (Ε.Φ.Κ.), σύμφωνα με τις διατάξεις του άρθρου 53 του παρόντα Κώδικα, θεωρούνται:

α) τα τσιγάρα,

β) τα πούρα και τα σιγαρίλλος,

γ) ο λεπτοκομμένος καπνός που προορίζεται για την κατασκευή χειροποίητων (στριφτών) τσιγάρων,

δ) τα άλλα καπνά για κάπνισμα.
