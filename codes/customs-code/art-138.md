# Άρθρο 138

_ΚΕΦΑΛΑΙΟ Ε΄ · ΑΛΛΕΣ ΔΙΑΤΑΞΕΙΣ_

Εγκατάλειψη υπέρ του Δημοσίου ή καταστροφή οχημάτων Οι διατάξεις του άρθρου 37 του παρόντα Κώδικα εφαρμόζονται αναλόγως και στις περιπτώσεις εγκατάλειψης ή καταστροφής κοινοτικών οχημάτων ή οχημάτων που έχουν τεθεί σε ανάλωση χωρίς την ταυτόχρονη καταβολή του τέλους ταξινόμησης.
