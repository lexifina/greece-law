# Άρθρο 189

Εξέταση ανακριτικών υπαλλήλων ως μαρτύρων Οποιοσδήποτε Οικονομικός Υπάλληλος (Οικονομικός Επιθεωρητής, Υπάλληλος Τελωνείου, υπάλληλος της Α.Α.Δ.Ε.), όταν ενεργεί ανακριτικές πράξεις για λαθρεμπορία ή συμμετέχει σε αυτές, δεν αποκλείεται να εξεταστεί ως μάρτυρας, κατά την ποινική διαδικασία στο ακροατήριο.
