# Άρθρο 57

Τέλη κυκλοφορίας ειδικών περιπτώσεων Κατά παρέκκλιση των άρθρων 55 και 56 επιβάλλεται τέλος κυκλοφορίας:

α) Για τα αλλοδαπά φορτηγά αυτοκίνητα, για κάθε ταξίδι, εκτός αν ορίζεται διαφορετικά από τις σχετικές διακρατικές συμβάσεις: εκατό (100) ευρώ.

β) Για τη χορήγηση προσωρινής άδειας κυκλοφορίας αυτοκινήτων οχημάτων και μοτοσικλετών σύμφωνα με την παρ. 8 του άρθρου 62: δέκα (10) ευρώ ανά ημέρα για τα αυτοκίνητα οχήματα και τρία (3) ευρώ ανά ημέρα για τις μοτοσικλέτες.

γ) Για τη δοκιμαστική κυκλοφορία των προς πώληση αυτοκινήτων οχημάτων από τους κατασκευαστές, εμπόρους και εν γένει αντιπροσώπους πωλήσεων:

γα) Για μοτοσικλέτες: τριάντα (30) ευρώ και

γβ) Για λοιπά οχήματα: εκατόν πενήντα (150) ευρώ.

δ) Για τα δίτροχα και τρίτροχα μοτοποδήλατα: δώδεκα (12) ευρώ.
