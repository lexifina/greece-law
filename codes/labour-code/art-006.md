# Άρθρο 6

Υποχρέωση πληροφόρησης Αν ο μισθός συνίσταται ολικά ή κατά ένα μέρος σε ποσοστό από τα κέρδη, ο εργοδότης έχει υποχρέωση να παρέχει στον εργαζόμενο ή αντί για αυτόν σε πρόσωπο που εκλέγουν τα μέρη ή το δικαστήριο, τις αναγκαίες πληροφορίες για τα κέρδη και τις ζημίες και, εφόσον απαιτείται, έχει υποχρέωση να επιδείξει τα λογιστικά βιβλία.
