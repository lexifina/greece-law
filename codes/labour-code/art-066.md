# Άρθρο 66

Προσφυγή από νομικά πρόσωπα και ενώσεις προσώπων Όταν νομικά πρόσωπα και ενώσεις προσώπων, συμπεριλαμβανομένων συνδικαλιστικών οργανώσεων, δικαιολογούν σχετικό έννομο συμφέρον και διαθέτουν γραπτή συναίνεση του θιγόμενου προσώπου του άρθρου 58 από παραβάσεις του παρόντος Τμήματος, εφαρμόζεται η παρ. 2 του άρθρου 51. Ο θιγόμενος μπορεί σε κάθε περίπτωση να παρέμβει ή και να ματαιώσει τη διαδικασία.
