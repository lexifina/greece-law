# Άρθρο 191

Εξασφάλιση συνεχούς λειτουργίας με εναλλαγή προσωπικού Επιτρέπεται η υπέρβαση του κατά άρθρο 180 ορίου των εργασίμων ωρών στις εργασίες των οποίων η συνεχής λειτουργία, λόγω της φύσης τους, πρέπει να εξασφαλίζεται με διαδοχικές εναλλαγές προσωπικού, υπό την προϋπόθεση ότι οι ώρες εργασίας δεν θα υπερβαίνουν κατά μέσο όρο τις 48 κατά εβδομάδα, σύμφωνα με το άρθρο 167. Στην περίπτωση αυτή πρέπει: α) η σειρά εργασίας των ομάδων να μεταβάλλεται κάθε εβδομάδα, ώστε η ομάδα που εργάστηκε κατά τη νύχτα της μιας εβδομάδας, να εργάζεται την επόμενη εβδομάδα σε ημερήσιες ώρες, β) κάθε φορά που μια ομάδα απασχοληθεί την Κυριακή να χορηγηθεί απαραίτητα σε αυτή εικοσιτετράωρη ανάπαυση σε άλλη ημέρα της εβδομάδας.
