# Άρθρο 227

Άδεια για υποβολή σε μεθόδους ιατρικώς υποβοηθούμενης αναπαραγωγής Εργαζόμενες, οι οποίες υποβάλλονται σε μεθόδους ιατρικώς υποβοηθούμενης αναπαραγωγής του ν. 3305/ 2005 (Α’ 17), δικαιούνται άδεια επτά (7) εργάσιμων ημερών με αποδοχές, ύστερα από βεβαίωση του θεράποντος ιατρού ή του διευθυντή μονάδας ιατρικώς υποβοηθούμενης αναπαραγωγής (Μ.Ι.Υ.Α.).
