# Άρθρο 232

Άδεια προγεννητικών εξετάσεων Οι έγκυες εργαζόμενες απαλλάσσονται από την εργασία χωρίς περικοπή αποδοχών, κατόπιν προηγούμενης ενημέρωσης του εργοδότη, με κάθε πρόσφορο μέσο, προκειμένου να υποβάλλονται σε εξετάσεις προγεννητικού ελέγχου, εφόσον αυτές οι εξετάσεις πρέπει να γίνουν κατά τη διάρκεια του χρόνου εργασίας.
