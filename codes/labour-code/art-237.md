# Άρθρο 237

Άδεια για μονογονεϊκές οικογένειες Στους εργαζόμενους γονείς, κατά την έννοια του άρθρου 218, που έχουν χηρέψει και στον άγαμο γονέα που έχει την αποκλειστική επιμέλεια παιδιού, χορηγείται άδεια έξι (6) εργάσιμων ημερών ετησίως, με αποδοχές, επιπλέον αυτής που δικαιούνται από άλλες διατάξεις. Γονέας με τρία (3) παιδιά ή περισσότερα, δικαιούται άδειας οκτώ (8) εργάσιμων ημερών ετησίως.
