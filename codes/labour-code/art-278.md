# Άρθρο 278

Προγραμματισμός αδειών Οι εργοδότες οι οποίοι απασχολούν εργαζομένους, που προστατεύουν πρόσωπα των περ. α) και β) του άρθρου 274, υποχρεούνται κατά τον προγραμματισμό του χρόνου χορήγησης των ετήσιων αδειών απουσίας του προσωπικού τους να λαμβάνουν υπόψη τις ανάγκες των εργαζομένων της κατηγορίας αυτής.
