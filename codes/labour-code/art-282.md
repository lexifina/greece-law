# Άρθρο 282

Ευνοϊκότερες ρυθμίσεις Ρυθμίσεις σχετικές με τα δικαιώματα που παρέχονται στους εργαζομένους από τις διατάξεις των άρθρων 273- 282, οι οποίες προβλέπονται σε συμφωνίες εργαζομένων και εργοδοτών ή σε συλλογικές συμβάσεις εργασίας ή διαιτητικές αποφάσεις, υπερισχύουν, εάν είναι ευνοϊκότερες.
