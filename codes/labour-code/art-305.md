# Άρθρο 305

Ιατρική πιστοποίηση

1. Η πιστοποίηση γίνεται από τον προϊστάμενο των υπηρεσιών υγείας ή από τους οριζόμενους απ’ αυτόν ιατρούς και καταχωρείται σε ειδική βεβαίωση με την ένδειξη κατάλληλος ή ακατάλληλος ή ακατάλληλος για ορισμένο χρόνο ή για ορισμένη εργασία.

2. Όταν η πιστοποίηση ισχύει για ορισμένη εργασία που απαιτεί ειδικές συνθήκες απασχόλησης ή επισημαίνει ανωμαλία στην ανάπτυξη ή ειδικά προβλήματα υγείας του εξεταζομένου, καθορίζει και τη χρονολογία επανεξέτασης καθώς και τα μέτρα που πρέπει να λάβει η Επιθεώρηση Εργασίας, για τον επαγγελματικό προσανατολισμό και την επαγγελματική επανακατάρτιση του ανηλίκου, σε συνεργασία με τις αρμόδιες για τα προγράμματα εξωσχολικού προσανατολισμού υπηρεσίες της Δ.ΥΠ.Α. και τις υπηρεσίες υγείας.
