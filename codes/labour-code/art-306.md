# Άρθρο 306

Αξιώσεις ανηλίκων

1. Ανήλικοι που απασχολούνται σε οποιονδήποτε εργοδότη έχουν όλες τις αξιώσεις που απορρέουν από έγκυρη σύμβαση εξαρτημένης εργασίας, ανεξάρτητα αν τηρήθηκαν οι διατάξεις για την πρόσληψη τους.

2. Οι διατάξεις του ν. 1346/1983 που ρυθμίζουν θέματα μαθητείας, καθώς και όσες δεν καταργήθηκαν με αυτόν, κατισχύουν των διατάξεων του άρθρου αυτού.
