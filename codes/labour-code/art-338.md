# Άρθρο 338

Αποχή από την εργασία λόγω ασθένειας βραχείας διάρκειας. Η αποχή του εργαζομένου από την εργασία, η οποία οφείλεται σε ασθένεια σχετικά βραχείας διάρκειας, η οποία αποδεικνύεται προσηκόντως ή, αν πρόκειται για γυναίκα, σε λοχεία, δεν θεωρείται ως λύση της σύμβασης εκ μέρους του. Ως βραχείας διάρκειας ερμηνεύεται η ασθένεια που διαρκεί ένα μήνα για εργαζομένους που υπηρετούν μέχρι τέσσερα έτη, τρεις μήνες για εργαζομένους που υπηρετούν για περισσότερα από τέσσερα έτη, όχι όμως περισσότερο από δέκα έτη, τέσσερις μήνες για υπαλλήλους που υπηρετούν περισσότερο από δέκα έτη, όχι όμως περισσότερο από δεκαπέντε έτη, και έξι μήνες για εκείνους που υπηρετούν περισσότερο από δεκαπέντε έτη.
