# Άρθρο 97

Παραπομπή μη προακτέου υπαλλήλου Υπάλληλος ο οποίος εγγράφεται σε δύο διαδοχικούς πίνακες μη προακτέων στον ίδιο βαθμό, παραπέμπεται μέσα σε δύο (2) μήνες από την κύρωση του οικείου πίνακα υποχρεωτικώς προς κρίση στο υπηρεσιακό συμβούλιο, το οποίο, με αιτιολογημένη απόφασή του και μετά από προηγούμενη κλήση αυτού, για να παράσχει εγγράφως ή προφορικώς τις αναγκαίες διευκρινίσεις, μπορεί να τον απολύσει ή να τον υποβιβάσει κατά έναν βαθμό. Κατά της απόφασης αυτής επιτρέπεται να υποβληθεί ένσταση στο Δευτεροβάθμιο Πειθαρχικό Συμβούλιο.
