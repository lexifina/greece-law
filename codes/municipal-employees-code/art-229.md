# Άρθρο 229

Κατάταξη αδιαβάθμιστου προσωπικού Το προσωπικό που υπηρετεί, μέχρι την ισχύ του παρόντος, σε αδιαβάθμιστες θέσεις του άρθρου 236 του ν. 1188/1981 (ΦΕΚ 204 Α΄), όπως είχε τροποποιηθεί και ίσχυε, κατατάσσεται, με απόφαση του αρμόδιου προς διορισμό οργάνου, σε προσωρινές προσωποπαγείς θέσεις, με την ίδια σχέση εργασίας που υπηρετούσε, και εξελίσσεται μισθολογικά σε όλα τα κλιμάκια της κατηγορίας όπου ανήκει. Για τη μισθολογική αυτή εξέλιξη, λαμβάνεται υπ’όψη όλη η πραγματική υπηρεσία ή προϋπηρεσία του.
