# Άρθρο 88

Εξουσιοδότηση υπογραφών Ο δήμαρχος μπορεί, με απόφασή του, να αναθέτει την υπογραφή, με εντολή του, εγγράφων και πιστοποιητικών, πλην χρηματικών ενταλμάτων, σε δημοτικό σύμβουλο ή στον πρόεδρο του συμβουλίου δημοτικού διαμερίσματος ή στον πρόεδρο του τοπικού συμβουλίου ή στον πάρεδρο ή στον γενικό γραμματέα του Δήμου ή σε προϊστάμενο δημοτικής υπηρεσίας ή σε άλλο μόνιμο υπάλληλο του Δήμου.
