# Άρθρο 182

Διάθεση − διαχείριση βοσκοτόπων Βοσκότοποι που ανήκουν στο κράτος διατίθενται για εκμετάλλευση στους Δήμους και στις Κοινότητες στην περιφέρεια των οποίων βρίσκονται, κατά προτεραιότητα, αποκλειστικά και μόνο για την ικανοποίηση κτηνοτροφικών αναγκών, εκτός αν ο νόμος ορίζει διαφορετικά.
