# Άρθρο 194

Μίσθωση ακινήτων από τους Δήμους και τις Κοινότητες Για ακίνητα που μισθώνουν οι Δήμοι και οι Κοινότητες γίνεται δημοπρασία. Αν η δημοπρασία που διεξήχθη δεν απέφερε αποτέλεσμα, μπορεί να γίνει απευθείας μίσθωση με ειδικά αιτιολογημένη απόφαση του συμβουλίου τους, η οποία λαμβάνεται με την απόλυτη πλειοψηφία του συνόλου των μελών του.
