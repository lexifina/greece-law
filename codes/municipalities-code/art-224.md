# Άρθρο 224

Συμπράξεις Δήμων και Κοινοτήτων με τον ιδιωτικό τομέα Για την εκτέλεση έργων και την παροχή υπηρεσιών, οι Δήμοι και οι Κοινότητες μπορούν να συνάπτουν συμβάσεις με νομικά πρόσωπα του ιδιωτικού τομέα, σύμφωνα και με τους όρους και τη διαδικασία του ν. 3389/2005 (ΦΕΚ 232 Α΄), όπως κάθε φορά ισχύει.
