# Άρθρο 285

Ενημερότητα οφειλών Προϋπόθεση για τη χορήγηση οποιασδήποτε μορφής αδειών από Δήμους και Κοινότητες είναι η μη ύπαρξη, εις βάρους του ενδιαφερομένου, βεβαιωμένων ληξιπρόθεσμων οφειλών προς αυτούς, με εξαίρεση τις περιπτώσεις εκκρεμοδικίας και του διακανονισμού καταβολής αυτών, σύμφωνα με τη σχετική νομοθεσία.
