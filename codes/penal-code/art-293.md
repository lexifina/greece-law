# Άρθρο 293

Παρακώλυση της λειτουργίας άλλων κοινωφελών εγκαταστάσεων 1. Όποιος παρεμποδίζει ή διαταράσσει σε μεγάλη έκταση ή για μεγάλο χρονικό διάστημα τη λειτουργία εγκατάστασης που εξυπηρετεί την παροχή στο κοινό: α) ταχυδρομικών υπηρεσιών, β) νερού, φωτισμού, φυσικού αερίου, θερμότητας ή κινητήριας δύναμης με αθέμιτη παρέμβαση σε πράγμα ή σε σύστημα πληροφοριών ή σε ηλεκτρονικά δεδομένα που εξυπηρετούν τη λειτουργία της εγκατάστασης, τιμωρείται με φυλάκιση τουλάχιστον ενός έτους και χρηματική ποινή. 2. Η παράγραφος 2 του άρθρου 292Β εφαρμόζεται και για την πράξη της παραγράφου 1. 3. Αν από την πράξη προκλήθηκε κατάσταση κοινής ανάγκης, επιβάλλεται κάθειρξη έως δέκα έτη. 4. Αν η πράξη τελέστηκε από αμέλεια, επιβάλλεται φυλάκιση έως έξι μήνες ή χρηματική ποινή.
