# Άρθρο 465

Οι διατάξεις του προϊσχύσαντος Ποινικού Κώδικα για τη μετατροπή της ποινής σε χρηματική ποινή, την αναστολή εκτέλεσης της ποινής και την απόλυση υπό όρο εφαρμόζονται για πράξεις που τελέστηκαν μέχρι τη θέση σε ισχύ του παρόντος. Σε περίπτωση αρχικής ή επιγενόμενης συρροής χρηματικής ποινής του άρθρου 80 του ισχύοντος Ποινικού Κώδικα με χρηματική ποινή του άρθρου 57 του προϊσχύσαντος ΠΚ ή ειδικών ποινικών νόμων που εξακολουθούν να ισχύουν, αυτές εκτίονται αθροιστικά.
