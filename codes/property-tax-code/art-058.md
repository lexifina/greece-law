# Άρθρο 58

_ΚΕΦΑΛΑΙΟ Β’ · ΧΡΟΝΟΣ ΦΟΡΟΛΟΓΙΑΣ_

Χρόνος γένεσης φορολογικής υποχρέωσης

1. Η φορολογική υποχρέωση γεννάται κατά τον χρόνο θανάτου του κληρονομουμένου.

2. Σε περίπτωση κήρυξης προσώπου ως άφαντου, η φορολογική υποχρέωση γεννάται κατά τον χρόνο δημοσίευσης στον τύπο της τελεσίδικης απόφασης που κηρύσσει την αφάνεια.
