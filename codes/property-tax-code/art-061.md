# Άρθρο 61

Αξία απαιτήσεων

1. Για απαιτήσεις που έχουν ως αντικείμενο χρηματικά ποσά λαμβάνονται υπόψη τα ποσά αυτά με τους τόκους που οφείλονται κατά τον χρόνο του θανάτου του κληρονομουμένου.

2. Οι απαιτήσεις, οι οποίες δηλώνονται από τον δικαιούχο της κτήσης ως εν μέρει εισπράξιμες, υποβάλλονται σε φόρο με βάση τη δηλούμενη αξία τους.
