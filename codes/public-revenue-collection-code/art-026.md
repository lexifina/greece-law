# Άρθρο 26

Ενέργειες σε περίπτωση αναστολής ή ματαίωσης πλειστηριασμού Εάν ο πλειστηριασμός δεν έγινε την ημέρα που ορίστηκε, εξαιτίας αναστολής ή ματαίωσής του, εκδίδεται νέο πρόγραμμα πλειστηριασμού χωρίς περιορισμό ως προς τον χρόνο έκδοσης και τον χρόνο διενέργειας του πλειστηριασμού. Για την κοινοποίηση και τις διατυπώσεις δημοσιότητας εφαρμόζονται οι διατάξεις του παρόντος Κώδικα.
