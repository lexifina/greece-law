History: **as enacted** (the official FEK text of ν. 5104/2024). Later amendments are not applied in this version; this is not the current consolidated text. ν. 5104/2024 enacted a new Tax Procedure Code in place of the one ratified by ν. 4987/2022 (the earlier version of this folder); the act's other provisions are kept here with it.

Source: <https://api.et.gr/apiLAW/1/2024/5104/pdf> (Εθνικό Τυπογραφείο, search.et.gr API). Text: PDF text layer (no OCR); running heads and page numbers of the Gazette dropped; lines joined into paragraphs. Checked: every 40-letter run of the stored text found in an independent Xpdf extraction (7676 of 7727).
