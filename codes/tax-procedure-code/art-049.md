# Άρθρο 49

Λήψη μέτρων σε περίπτωση υπόνοιας καταδολίευσης

1. Σε εξαιρετικές περιπτώσεις που υπάρχουν πληροφορίες ή υπόνοιες ότι ο φορολογούμενος θα προβεί σε μεταβίβαση περιουσιακών του στοιχείων ή προβαίνει σε προπαρασκευαστικές ενέργειες, για να εγκαταλείψει τη χώρα, ή σε οποιαδήποτε άλλη ενέργεια που θέτει σε κίνδυνο την είσπραξη του φόρου, η Φορολογική Διοίκηση μπορεί να λαμβάνει, με βάση τον εκτελεστό τίτλο, μέτρα αναγκαστικής εκτέλεσης ακόμη και πριν τη νόμιμη ημερομηνία καταβολής της οφειλής ή την κοινοποίηση της ατομικής ειδοποίησης ή την παρέλευση της τριακονθήμερης προθεσμίας που προβλέπεται στο άρθρο 47 για την καταβολή της οφειλής.

2. Με τις προϋποθέσεις που αναφέρονται στην παρ. 1 μπορεί επίσης να εγγράφεται υποθήκη.

3. Σε περίπτωση που ο φορολογούμενος μεταβιβάσει περιουσιακά στοιχεία του, η Φορολογική Διοίκηση μπορεί να προβαίνει στην άσκηση αγωγής διάρρηξης για τη διασφάλιση των συμφερόντων του Δημοσίου, σύμφωνα με τα άρθρα 939 επ. του Α.Κ.. Στην περίπτωση αυτή η Φορολογική Διοίκηση μπορεί να ζητήσει ως ασφαλιστικό μέτρο τη δικαστική μεσεγγύηση σύμφωνα με τα άρθρα 725 επ. του Κ.Πολ.Δ..
