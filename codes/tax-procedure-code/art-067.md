# Άρθρο 67

Κυρώσεις σε περίπτωση υποτροπής Σε περίπτωση υποτροπής επιβάλλεται χρηματικό πρόστιμο διπλάσιο του προβλεπόμενου για την αρχική παράβαση και, σε κάθε περίπτωση νέας υποτροπής, επιβάλλεται πρόστιμο τετραπλάσιο του προβλεπόμενου για την αρχική παράβαση, εκτός αν προβλέπεται διαφορετικά στον παρόντα Κώδικα.
