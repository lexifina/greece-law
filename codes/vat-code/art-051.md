# Άρθρο 51

Κοινοποίηση των πράξεων Οι πράξεις τις οποίες προβλέπουν οι διατάξεις των άρθρων 49 και 50 κοινοποιούνται στον υπόχρεο μαζί με τη σχετική έκθεση ελέγχου, κατά τις διατάξεις του Κώδικα Διοικητικής Δικονομίας. Αν η υπόθεση περαιωθεί ως ειλικρινής, τούτο γνωστοποιείται στον υπόχρεο με απλή ταχυδρομική επιστολή.
