# ν. 5177/2025

Κώδικας εμμέσων φόρων επί των συναλλαγών του πεδίου εφαρμογής του Κώδικα Φορολογικής Διαδικασίας, καθώς και λοιπών εμμέσων φόρων (Code of Indirect Taxes on Transactions). The text of this act is kept with the code: [codes/indirect-transaction-taxes-code/](../../../codes/indirect-transaction-taxes-code/README.md).
